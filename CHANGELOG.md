# История версий

Формат версий: основная.дополнительная.исправление. Каждая версия отмечена тегом в git (`v1.1.0`)
и лежит в `releases/` как архив исходников.

## 1.1.0 — 2026-10-29

### Windows
- Звуки для сна на экране ночной блокировки: дождь, белый шум, коричневый шум, волны. Генерируются самой программой.
  Свои mp3/wav кладутся в `%APPDATA%\FocusWall\sounds` и появляются в списке. Выбор на экране блокировки и в меню значка в трее.
- Задача планировщика «FocusWall Daily»: программа сама запускается каждый вечер в 21:00, даже если её закрыли.
  Вместе с «FocusWall Watchdog» (проверка раз в минуту) и автозапуском при входе в Windows. Установщик удаляет обе задачи.
- Аварийный выход из ночной блокировки только через безопасный режим Windows (описано в README).

### Android
- Разблокировка на 3 минуты один раз за ночь блокировки: кнопка на экране блокировки, обратный отсчёт внизу экрана
  поверх приложений, по окончании блокировка включается снова и закрывает открытое. Тест на границу ночи через полночь.
- Фильтр сайтов быстрее замечает начало и конец разблокировки (проверка раз в 3 секунды вместо 15).

### Общее
- Версия 1.1.0 во всех трёх частях: расширение, приложение Android (versionCode 2), приложение Windows.

## 1.0.0 — 2026-10-27

- Расширение для браузера (Chrome, Edge, Brave): чёрный и белый списки, расписание, сессии, жёсткий режим, вход через Google.
- Приложение Android: блокировка приложений (служба специальных возможностей) и сайтов (локальный DNS-фильтр), экраны со списками и расписанием.
- Приложение Windows 10: значок в трее, автозапуск, сторож в планировщике, полноэкранная блокировка по расписанию.
- Расписание по умолчанию: каждый день с 21:00 до 05:00. Ночью на компьютере блокируется всё, на телефоне остаются звонки, Сбербанк Онлайн и часы.
- Синхронизация через Firebase (вход Google), автосборка на GitHub Actions.
